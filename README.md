# Clothing Store Mobile App Prototype

This was an earlier React Native project for an online clothing-store prototype.

I built the project to practise navigation, user interaction, data persistence and the structure of a multi-screen mobile application.

## Main parts

- login and registration screens
- user profile
- product categories
- product browsing
- shopping cart
- screen-to-screen navigation

## Technologies

React Native · JavaScript · Firebase · Redux

## Project structure

The repository is organised into screens, navigation, components, reducers and configuration files. The original screenshots are kept in the README to show the interface that was developed.

## Project status

This is an older learning/coursework prototype rather than a production e-commerce application.

One important note: the Firebase configuration in the original project is legacy coursework configuration. It should not be reused for a new application. Any new version should use a fresh Firebase project and proper environment/configuration handling.
