# Clothing Shopping App Prototype — React Native

This was an earlier React Native project exploring the structure of a simple clothing shopping application for Android and iOS.

## Main parts
- Login and registration screens
- User profile
- Product categories
- Product browsing
- Shopping cart flow
- Navigation between screens
- State/data management

## Technologies
React Native · JavaScript · React Navigation · Redux

## What I learned

The project helped me understand screen navigation, touch interactions, component structure and separating application state from the user interface.

## Project status

This is a prototype and an earlier development project. It is kept as part of my software-development portfolio and is not presented as a finished commercial shopping application.
